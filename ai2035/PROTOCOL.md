# 研究规范（所有 20 个项目共同遵守）

## 目录约定
```
ai2035/projects/Qxx-<slug>/
  README.md        分析报告（中文），即本项目的交付物
  experiment.py    可复现实验；`python ai2035/projects/Qxx-<slug>/experiment.py` 从仓库根目录运行
  results/         由 experiment.py 生成：results.json + 图（png）
```
共享工具：`ai2035/common/util.py`（`rng`, `save_results`, `mean_ci`, `plt`——已配置中文字体）。
实验在文件开头用 `sys.path.insert(0, str(Path(__file__).resolve().parents[2]))` 后 `from common.util import ...`。

## 科学严谨性要求
1. **问题可检验化**：把宏观的基础科学问题收窄为 1–3 个可证伪的子假设（H1, H2…），写明“若出现何种结果则假设被否定”。
2. **实验**：仅用 numpy / scipy / scikit-learn / matplotlib（无 PyTorch、无 GPU、无外网数据；可用 sklearn 自带数据集如 digits）。
   - 至少 5 个随机种子，报告均值 ± 95% 置信区间；比较时给出效应量或配对检验（scipy.stats）。
   - 必须设对照组 / 基线；参数在实验前固定，不得看结果后挑选。
   - 单个 experiment.py 单核运行时间 ≤ 3 分钟。
   - 报告中的每个数字都必须能在 results/results.json 中找到。
3. **证据分级**：报告中的论断按来源标注——
   - **[实测]** 本项目实验直接得出；
   - **[文献]** 来自已核实的参考文献；
   - **[判断]** 作者基于证据的推断 / 预测，须说明理由。
4. **参考文献核实**：只引用确定存在的文献。arXiv 论文须用 arXiv 编号，并通过
   `https://export.arxiv.org/api/query?id_list=ID1,ID2,...&max_results=50`（一次批量查询，两次请求间隔 ≥3 秒）核对标题一致；
   非 arXiv 的经典文献（如 Hopfield 1982）给出作者、年份、期刊。不确定的不要写。
5. **诚实边界**：玩具实验只能为机理提供证据，不能代表大规模系统的结论；“效度威胁”一节必须写明外推边界。
