# AI app radar: analysis, 2026-10-19

Commentary on [the radar's report for today](2026-10-19.md). This is day one,
so read every number with three caveats:

- **No growth here is measured by the radar yet.** Open-source figures are stars
  gained as stated on GitHub's trending pages. Commercial figures are
  company-reported or tracker-reported. Re-observation starts tomorrow.
- **Commercial figures came from search-result summaries.** The collector's
  fetch tool could not open the source pages in this session, so every
  `reported` figure needs a check against the URL it cites before anyone relies
  on it.
- **Hugging Face and Hacker News could not be reached** from the cloud sandbox.
  Today's picture is GitHub plus reported company metrics. Spaces, models and
  launches are missing.

## Summary

- **The agent toolchain is where open-source growth is.** 17 of the top 25 are
  coding agents or tooling around them: memory, orchestration, skills, context
  compression, gateways and security. Only a few are end-user applications, and
  the ones that are (ai-job-search, diagram-design) ship as agent skills.
- **Security for autonomous agents is the strongest new direction.** 80% of
  tracked security repos are in the top quartile. A lexical grouping the tag
  vocabulary did not name ("agents / autonomous") pulls together
  cloudflare/security-audit-skill, ifixai-ai/iFixAi, NVIDIA/OpenShell and
  morluto/rea.
- **Generative video is the commercial breakout.** Higgsfield is the
  highest-ranked commercial app: a reported $700M to $1B run-rate in 25 days
  ([arr.club](https://www.arr.club/signal/higgsfield-arr-hit-1b-with-20x-growth-in-the-past-12-months)).
  Runway and HeyGen each passed $200M by doubling in 5 to 8 months (see notes).
- **Revenue numbers are getting less comparable.** OpenAI's reported run-rate was
  cut by about $20B once cloud-partner accounting was separated out
  ([TechCrunch](https://techcrunch.com/2026/10/08/openais-revenue-is-reportedly-20-billion-less-than-previously-projected/)).
  The radar discounts reported figures for exactly this reason.
- **Biggest single caveat:** the #3 repo, morluto/rea, shows a stated gain of
  229k stars in one week. It is flagged and discounted (see *Anomalies*).

## Directions

All directions are new today, so there is no change to report. The ordering by
top-quartile share:

1. **Agent orchestration** (100%), **security** (80%) and **agent memory**
   (67%) lead. All three are layers *under* coding agents, consistent with the
   [coding-agent spend data](https://dealroom.co/news/134107-cursor-tops-4b-annualized-revenue/):
   as Cursor, Cognition, Lovable and others turn into multi-billion-dollar
   businesses, the open-source layer around them grows fast.
2. **Coding agents** themselves have the most apps (21) but only an 18%
   top-quartile share. The direction is crowded, and growth is spread across
   many tools rather than concentrated.
3. **The Claude Code plugin ecosystem** shows up as an emergent grouping
   ("plugins / claude / terminal"): anthropics/claude-code,
   anthropics/claude-plugins-official, anthropics/knowledge-work-plugins and
   third-party projects. A platform ecosystem is forming around one agent.
4. **Assistants and legal** rank at the bottom. That is not because they are
   shrinking. Their evidence is a few months-old reported figures, which the
   radar discounts by age. Coverage, not momentum, is what is low there.

## Innovation opportunities

The radar raised nine hypotheses. Researched against today's evidence:

- **Agent security, open source ahead of product. Strongest hypothesis.** Five
  fast-growing open projects and no commercial product tracked. The gap is not
  that no vendors exist; the radar's collectors simply do not see security
  companies. What would have to be true for it to be worth building: enterprises
  adopting autonomous coding agents (Cursor reports about 75% enterprise revenue,
  see notes) need audit, sandboxing and policy enforcement they will pay for
  separately from the agent vendor. Next step: collect agent-security vendors'
  reported metrics so the hypothesis can be tested rather than assumed.
- **Agent memory, fast and uncrowded.** Three repos, two from established
  companies (vectorize-io, TencentCloud). A hosted, cross-agent memory layer is
  the obvious product. The risk is that agent vendors build memory in themselves.
- **Agent orchestration.** Only two tracked apps, so the radar's evidence is too
  thin to call it uncrowded. Treat as *watch*, not *act*.
- **Design and local LLM, open source ahead of product.** These are artefacts of
  having two apps per direction. Dropped until more data arrives.
- **Voice, fast and uncrowded. Rejected.** The radar tracks three voice apps,
  but ElevenLabs alone is pacing $600M ARR and support-agent companies (Sierra,
  Decagon) are at $100M to $200M (see notes). The space is crowded commercially.
  The radar just cannot see it yet.
- **The radar agent's own hypothesis: skills as an app distribution format.**
  ai-job-search, diagram-design, scientific-agent-skills and Cloudflare's
  security skill are end-user applications shipped as agent skills rather than
  as apps. If that continues, the scarce asset becomes discovery and trust for
  skills (a marketplace, ratings, security review), not building them.

## Radar self-critique

- **Biased toward GitHub.** 45 of 72 apps are repos, because GitHub trending was
  the only open source that worked. Hugging Face (models and Spaces) and Hacker
  News (launches) are both unreachable from the sandbox. The environment's
  network settings need `huggingface.co` and `hn.algolia.com` allowed, or the
  GitHub Actions collector needs to be merged.
- **Commercial apps cannot be re-measured.** Repos can be re-observed tomorrow;
  products only appear when a company publishes a number. That is the
  highest-value item in the backlog.
- **The scorecard is empty until about 2026-10-27.** Until then the ranking is
  untested. Nothing the radar says should be read as validated before the first
  scorecard appears.
- **Biggest single improvement for tomorrow:** re-observe the top 40 repos
  (`airadar recheck`). That converts today's stated claims into growth the radar
  measured itself, and it produces the first data the forecast scorecard can
  check.
