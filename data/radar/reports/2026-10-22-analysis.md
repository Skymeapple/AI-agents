## 4. Innovation opportunities

- **"Fast and uncrowded: context-compression": partly disproved.** It is fast
  but crowded:
  - OpenAI ships a compaction endpoint ([OpenAI](https://developers.openai.com/api/docs/guides/compaction.md), [snippet]).
  - Anthropic ships compaction in the Messages API ([AWS](https://docs.aws.amazon.com/bedrock/latest/userguide/claude-messages-compaction.html), [snippet]).
  - Gateways pass it through ([LiteLLM](https://docs.litellm.ai/docs/claude_code_context_management), [snippet]).
  - YC startups are in it (Compresr, [snippet](https://compresr.ai/); The Token Company, [snippet](https://www.ycombinator.com/companies/the-token-company)).
  - Graphify sells "token spend" reduction itself.

  **The gap that remains:** vendor compaction works only inside one
  provider's API; Vercel's gateway rejects it for other providers
  ([Vercel](https://vercel.com/docs/ai-gateway/sdks-and-apis/responses/compaction), [snippet]). No independent quality benchmark was found. It is worth building
  only if multi-provider agent stacks are common and a neutral benchmark can be
  produced. *(The cross-provider gap is the radar agent's inference.)*
- **agent-memory, agent-orchestration, generative-ui, llm-gateway: all
  disproved earlier** ([2026-10-20](2026-10-20-analysis.md) §4,
  [2026-10-21](2026-10-21-analysis.md) §4). The rules re-propose them because
  the incumbents are not tracked (§5).
- **Two of the radar agent's own:**
  - *(radar agent's hypothesis)* **Safe-by-default runtimes for agents that
    act externally.** harvey sends email and recommends skipping permission
    prompts; ai-job-search added a prompt-injection guard; Pluto Security
    raised $42M around AI-built apps
    ([TechCrunch](https://techcrunch.com/2026/10/13/pluto-security-raises-42m-as-ai-gives-enterprise-security-teams-a-new-headache/), [snippet]). A sandboxed, per-action
    approval runtime that sales and job agents could adopt instead of
    "skip permissions" is the gap. It is worth building if skill authors keep
    shipping that flag.
  - *(carried)* **Trust and ranking for skill and plugin marketplaces.** Two
    repos that ranked on doubtful signals vanished this week (dsh-purge, then
    dsh-workbuddy-connect). Independent usage and safety signals remain the
    scarce asset.
