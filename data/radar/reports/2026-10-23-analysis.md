## 4. Innovation opportunities

- **"Fast and uncrowded: agent-runtime": the "uncrowded" half is disproved.**
  Hosted sandboxes have many funded players:
  - Modal ([dealroom](https://dealroom.co/news/129203-modal-raises-355m-series-c-at-4-65b-valuation/), [snippet])
  - Daytona (above)
  - E2B ([startupintros](https://startupintros.com/news/2025-07-01-e2b-series-a), [snippet])
  - Runloop ([pulse2](https://pulse2.com/runloop-7-million-seed-funding-raised-to-bring-enterprise-grade-infrastructure-to-ai-coding-agents/amp/), [snippet])
  - Cloudflare Sandboxes, GA since April ([Cloudflare](https://developers.cloudflare.com/changelog/2026-04-13-containers-sandbox-ga), [snippet])
  - Vercel Sandbox

  **The narrower gap is the self-hosted policy and governance layer:**
  egress policy per request, credential brokering, audit logs, and on-prem or
  edge deployment. That is exactly where NVIDIA has placed OpenShell. A
  startup there now competes with an NVIDIA-backed open standard. That makes
  it worth building on, not against.
- **agent-memory, agent-orchestration, generative-ui, llm-gateway:**
  disproved on earlier days ([10-20](2026-10-20-analysis.md),
  [10-21](2026-10-21-analysis.md)). They are still re-proposed by the rules.
- **Two of the radar agent's own:**
  - *(radar agent's hypothesis, updated)* **A safe-by-default harness for
    agent skills.** Cloudflare's skill expects an OS-enforced sandbox but
    doesn't ship one ([page](https://github.com/cloudflare/security-audit-skill)).
    harvey's README recommends skipping permission prompts
    ([page](https://github.com/ethanplusai/harvey)). OpenShell supplies the
    policy runtime. The missing piece is packaging popular skills to run
    inside such a runtime by default. It is worth building if OpenShell or a
    peer becomes the common layer.
  - *(carried)* **Trust and ranking for skill marketplaces.** Unchanged since
    Oct 21; still unbuilt.

## 5. Radar self-critique

- **Improvement made today: moved apps keep one history.**
  - `airadar mark-moved` appends an alias (old id → new id and url, with the
    page that shows it) to `aliases.jsonl`.
  - Apps, observations and gone records resolve through it when read; the
    observations file is never rewritten.
  - ai-job-search now appears once, as ai-job-search-dev/ai-job-search, with
    its history back to Oct 19.
- **The ranking still leans on stale stated gains.** ai-job-search (#2),
  artcraft (#6) and ai-memory (#9) rank on gains stated up to 4 days ago,
  while the radar's own measurements show them cooling or off trending.
  - The fixed `lookback_days` is 7, so a stated one-day gain from Oct 19
    still counts.
  - This should be settled by the scorecard (first matured forecasts about
    Oct 26–27) and the tuner's `weight.delta` / `weight.period`, not by hand.
  - If the tuner can't move them, a freshness decay for stated (period)
    signals, like the one reported figures already have, is the next
    candidate. Added to the backlog.
- **Trending pages are read short.** Every page returned 9–20 repos, not 25,
  for the second day. Repos ranked lower on those pages are invisible.
- **Sources are unchanged:**
  - GitHub only for open source.
  - All 11 company figures are search snippets; Hugging Face and HN are
    unreachable; Tavily is over quota.
- **Scorecard:** no matured forecast yet. Tuning held.
