## 4. Innovation opportunities

- **All 3 rule-generated hypotheses already carry research verdicts.**
- **Two of the radar agent's own:**
  - *(carried, strengthened)* **Design review as a service for agent-built
    frontends.** A fourth design skill reached trending today, and the
    category's leaders add 1.4–2.3k stars a day each. The open gap is still
    enforcement after generation (visual QA against a brand system), not
    more prompt-level skills.
  - *(radar agent's hypothesis, new)* **A shared control plane for local agent
    workspaces.** openbot, cindy and thinkrail each build their own way to run
    and steer several coding agents on one machine. humanlayer does it across
    a team ([page](https://github.com/humanlayer/humanlayer)). A common
    protocol for agent sessions (attach, steer, hand off, audit) would let
    these clients interoperate. Worth building if a dominant client doesn't
    emerge within a few months.
