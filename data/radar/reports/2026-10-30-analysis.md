## 4. Innovation opportunities

- **All 3 rule-generated hypotheses already carry research verdicts.** None
  was re-researched.
- *(radar agent's hypothesis, carried)* **A shared control plane for local
  agent workspaces.** Two more clients arrived today, both built around an
  agent having its own computer. Each still invents its own session and
  sandbox model, so the case for a common protocol (attach, steer, hand off,
  audit) is stronger.
- *(radar agent's hypothesis, new)* **Jailbreak-resistance testing as a
  service.** The fastest-growing repo on the radar is a public library of
  jailbreak prompts for 26+ models. Agent products built on those models
  inherit the exposure.
  - Security vendors are already there for models: Alice, HiddenLayer and
    iFixAi are on the radar.
  - The gap would be continuous regression testing of a specific deployed
    agent against newly published prompt libraries.
  - It is worth building only if it is cheaper than the vendors' red-teaming
    and keeps pace with libraries that change weekly.
