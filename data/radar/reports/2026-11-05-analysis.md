## 3. Directions

- **computer-use (new):** 14 apps, 43% of them in the top quartile, mean
  score 0.55. Leaders: agent-desktop, AnyModelBot (see §2a) and
  onehumanbeing/esp32-iphone-agent. It sits alongside mobile-agent (phone agents such as
  phone-harness).
- **Agent autonomy and long-running work:** agent-autoloop (background
  agent that escalates only decisions) and gstack (a role-based Claude Code
  setup) join the agent workspaces (openbot, cindy, Orkas).
- **Local inference at the extreme:** kimi-k3-in-c claims to run a
  2.78-trillion-parameter model on one CPU (trending listing). It is a
  claim, not a measurement.

    browser-use and browser-use-agent map to it. A test pins it.

  conversations" counts usage, not users or revenue. That is consistent with
