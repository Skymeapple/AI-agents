  ([pulse2](https://pulse2.com/copilotkit-27-million-series-a-raised-for-enterprise-agentic-frontend-stack/), [snippet]).
  Verdict recorded.
- **context-compression** remains the only unresearched rule.
- *(radar agent's hypothesis, carried)* **Sandboxed computer use for
  agents.** Partly pre-empted. E2B already sells agent cloud computers at a
  $100M+ run rate. The remaining gap is desktop and phone control
  (agent-desktop, Mika, phone-harness) with the same isolation and audit,
  not cloud sandboxes.
