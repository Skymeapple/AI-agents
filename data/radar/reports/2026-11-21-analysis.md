## 5. Radar self-critique

- **Improvement made today: a stale-page check.** `validate` and the
  ingest log now warn when a page-read star or like count is below the
  radar's own latest API reading of the same app (rounding and 0.5%
  allowed). On yesterday's rejected trending file it flags 27 of 29
  checkable rows; on Nov 15–19's files it flags none. Today's file passed.
  A test pins it.
- **New gap: one-day API dips create false movers.** xerj's 17,961
  reading sat between two readings near 19,200, and the radar counted the
  recovery as +1,160. A reading that falls and recovers within a day
  should not count as growth on either side.
- **New gap: re-uploads of reviewed fakes.** A verdict attaches to one
  repo URL, so a copy under a new owner starts clean. The clone check needs
  five owners; a single re-upload with an identical description is cheaper
  to catch.
- **Forecast:** Nov 14 scored 0.22 on its top 100 (relative gain 0.50).
  The tuner, on the top-100 score, found shrinkage → 0.25 at +0.019, just
  under the +0.02 bar.
- **Sources:** Hacker News and npm are still refused by the proxy.
