## Pick: ctxlint

* Evidence that the pain is real: an r/codex thread on keeping AGENTS.md and CLAUDE.md in sync, InfoWorld's report that monorepos "quietly drift out of sync", a 138-repo study showing files restate the repo and bloat, and Pillar's Rules File Backdoor research.
* Existing tools: `agentlint` on npm is security-focused, and `agents-doctor` only checks AGENTS.md. Neither verifies the files' claims against the real repo (do the scripts, paths and make targets still exist?) or detects drift across formats.
* Validation: we ran it on openai/codex, google-gemini/gemini-cli, vercel/ai, anthropics/claude-code-action, astral-sh/uv and microsoft/vscode, and tuned it until there were zero false positives. It found genuine stale references in VS Code and oversized files in VS Code and vercel/ai.
