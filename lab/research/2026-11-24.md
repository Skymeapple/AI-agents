## Phase 0 finding: name collision

While re-checking the unpublished names across registries, I found that **`agentscrub` exists on PyPI**: https://github.com/ppravdin/agentscrub, 44 releases since 2026-05-07, "Find and redact leaked secrets in local AI coding-agent logs". On Day 2 the name check only queried npm.

Feature comparison from its README:
* **It covers more:** local agent logs, histories and caches across many agents, with backups, cron and stdin redaction. This is more thorough than our `--sessions` / `--home`.
* **It doesn't cover** (0 README mentions): project `.claude/settings*.json` allowlists and their auto-fix; project `.mcp.json` files; agent hooks; pre-commit; CI; git exposure grading.

**Decision:** our tool keeps a distinct job, keeping agent-saved secrets out of *git*, but can't use the name. Renamed to **`agent-commit-guard` 0.3.0** before the first publish (free on npm, including scoped names, and on PyPI). The README is repositioned around the commit guard, and the comparison table credits agentscrub and recommends using both.
