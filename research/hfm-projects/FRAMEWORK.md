# 用“四个同构 + 四层路线”逐一处理 54 个项目

本页把用户提出的框架（四个跨领域同构映射、四层路线图）落到 54 个项目上。原则是**把框架当作待检验的假设**：每个项目写出它属于哪个同构、哪一层是瓶颈、已有实验是支持还是反对，以及下一步能做的具体实验。已经跑出的证据都链接到项目目录；本页新增的实验写在最后的“框架检验”一节。

所有数字都是公开数据上的替代实验，不能与 HFM 私有评测上的分数直接比较。

## 一、框架要点（摘要）

| 编号 | 内容 | 在本仓库里怎样检验 |
|---|---|---|
| 同构 A | 把 Lean 的“生成 → 验证 → 诊断 → 修复”推广为各领域的“广义验证器” | Lean、Dafny 的模型加验证器实验；运筹类项目的可行性检查加局部修复（LNS） |
| 同构 B | 测序批次、风场、天区、城市、市场之间的差异，都是“环境变量污染不变机制”，可用同一套不变性方法 | 共享模块 [`_framework/invariance.py`](_framework/invariance.py)，同一套方法、同一个“留一环境”协议，跑在多个项目上 |
| 同构 C | 钢材滞回、对流失稳与订单簿耗竭、路网拥堵同属路径依赖、临界相变系统，可迁移物理方法 | 在订单簿和交通类项目里加入“历史记忆”特征或状态空间模型，看是否超过只看当前状态的模型 |
| 同构 D | AI-for-AI 底座（预训练、后训练、智能体框架）反哺现实问题 | 智能体框架实验里学到的规律（例如“先廉价自动化、再调模型”）能否在其他项目复用 |
| 第 1 层 | 三级验证金字塔：L1 解析/守恒过滤，L2 代理模型，L3 高保真仿真或真实实验 | 晶体生成（便宜筛选再算 DFT）、Lean（策略组合再调模型） |
| 第 2 层 | 物理/因果骨架 + 神经网络残差 | 风场尾流、冷电池、PM2.5、大坝气体、光学常数 |
| 第 3 层 | 失败感知的研究树搜索，保留全部失败证据 | 本仓库每个项目保留负结果；终端智能体框架实验检验“在噪声上接受改动”的风险 |
| 第 4 层 | 预测—决策一体化与跨任务元框架 | 共享骑行、机组组合、组合优化里比较“先预测再优化”和“直接按决策效用训练” |

## 二、已有证据对框架的总体判断

- **同构 A 得到最强支持，但验证器只是必要条件。** Lean：零模型策略组合 42.2%，加开源模型 52.5%，再用策略组合修补模型草稿 54.9%，再加 8 次修补采样 138/244 = 0.5656（[Lean 项目](agent-harnesses/lean-prover-agent/README.md)）。修补带来的新增和“多采样 8 次”相当，而且不增加模型调用。Dafny：让模型整段重写程序再验证，82 个程序全部失败（大量格式改动、语法错误）；改为“模型只提议不变式、验证器剪枝”后正在重跑。教训是：广义验证器要配合**受约束的生成接口**，否则验证器只会一再拒绝。
- **第 2 层（物理骨架 + 残差）是条件性成立。** 支持：风场尾流在未见风场上“物理 + 残差”最好（−29.8%）；冷电池用 Arrhenius 形式外推技能 +0.34 对 +0.15，并在第二块电芯复现。反对：大坝气体模型中线性模型胜过饱和物理形式（1.80 对 2.02）；PM2.5 中物理湿度增长形式没有带来增益。规律是：物理形式要在**外推方向**上起约束作用才有用；在插值范围内，它常常不如灵活模型。
- **同构 B 还没有直接证据。** 已有跨环境的成功（肺细胞 35 个研究全部提升、测光红移每个天区都提升、PM2.5 跨城市 +10%）来自**更好的输入或更灵活的模型**，不是来自不变性方法。本页第四节用同一套不变性方法在多个项目上直接检验。
- **同构 C 得到支持。** 加入路径记忆特征后，四个币种的深度排序全部提升；消融显示主要贡献来自类比所主张的“相对近期峰值的回撤、离近期最低点的距离”，而不只是普通滞后（第四节）。
- **第 4 层有部分支持（本轮新增共享单车检验，见第四节：决策导向调参比预测导向多 1 个百分点）。** 机组组合用“分散情景”的决策导向承诺，比调好的备用规则后悔值低 23%；共享骑行中完美预测只多带来 11%，说明预测精度不是唯一瓶颈。组合优化中“部分交易”胜过“漂移触发”，也是按净效用而不是按预测精度选方法。

## 四、框架检验（本轮新增实验）

1. **同构 B：同一套不变性方法跨项目。** 共享模块 [`_framework/invariance.py`](_framework/invariance.py) 对任意 (X, y, 环境) 表比较七种方法：普通 ERM、环境等权、group DRO、环境内标准化、神经网络 ERM、V-REx、IRM。协议统一为“留一环境”，惩罚强度只在训练环境内选择。适配器 [`_framework/run_invariance.py`](_framework/run_invariance.py) 目前接入 PM2.5（城市、站点）和测光红移（六个天区带）。

   **测光红移（198,350 个 SDSS 星系，六个 60° 赤经带，留一带）：同构 B 被否定。** 平均 / 最差 RMSE：ERM 0.0625 / 0.0793；环境等权 0.0630 / 0.0798；group DRO 0.0636 / 0.0797；环境内标准化 0.0691 / 0.0940；神经网络 ERM 0.0650 / 0.0814；V-REx 0.0652 / 0.0814；IRM 0.0659 / 0.0820。没有任何不变性方法在多数天区胜过各自的基准（V-REx 只在 1/6 个天区略好于神经网络 ERM），连最差天区也没有改善。环境内标准化最差，因为它抹掉了天区之间真实的星等水平差异。日志：[`invariance-photoz`](../compute/results/invariance-photoz/run.log)。

   **解读。** 这里的天区差异主要是协变量分布的移动（深浅、消光不同），输入到红移的机制本身相同；这时普通 ERM 已经学到的就是不变机制，不变性惩罚只会损失拟合。项目里真正有效的跨天区改进是**加入能解释差异的输入**（消光、尺寸，−5.8%），也就是把“环境变量”显式建模，而不是把它惩罚掉。PM2.5 结果待填。
2. **同构 C：订单簿的“路径记忆”。** [`memory_floor.py`](quant-finance/order-book-depletion/memory_floor.py) 在当前状态的 8 个特征之外加入路径特征：一分钟内的深度变化滞后、相对 5 分钟和 30 分钟峰值的回撤（类比累积塑性应变）、相对 30 分钟最低点的距离（离“耗尽”状态多近）、多尺度成交和波动。Bybit 四个永续合约，前两天拟合，第三天测试。**四个币种全部提升**（梯度提升树的 Spearman：BTC 0.585 → 0.601，ETH 0.578 → 0.602，SOL 0.485 → 0.528，XRP 0.319 → 0.361；前 10% 命中率同样四个全部提升，例如 XRP 0.247 → 0.286）。**消融结果支持类比本身：** 只加 3 个“回撤/离最低点距离”特征，就是四个币种中最好的单组（BTC 0.597、ETH 0.598、SOL 0.518、XRP 0.358，普通滞后组分别为 0.589、0.585、0.515、0.349）；在“滞后 + 成交 + 波动”之上再加它们，四个币种仍全部提升（例如 SOL 0.514 → 0.528）。也就是说，盘口相对其近期“加载历史”所处的位置（类比塑性应变累积）带来了普通自回归之外的信息。这是本轮框架检验中唯一一个被证据明确支持的同构。
