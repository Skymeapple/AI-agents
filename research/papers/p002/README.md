# p002 — How far can a fixed-rollout evaluation see? (test-time-compute extrapolation limits)

Paper: `paper.md`.  All numbers in the paper come from the scripts below; outputs are in `results/`.

## Requirements
Python 3 with numpy, scipy, pandas, matplotlib, plus `python-sat` (exact SAT labels) and `cvxpy`
(lower bounds, uses the bundled CLARABEL solver); gcc for the WalkSAT generator.

    pip install python-sat cvxpy
    gcc -O3 -o code/walksat code/walksat.c

## Run (about 45 CPU-minutes total on 4 cores)
    cd code
    python3 exp_theory.py          # E_n for pass@k / majority / verifier ceiling / best-of-k; duality check; fig_theory.png
    python3 exp_theory_check.py    # Newman-Rivlin sandwich, closed form of Thm 3, horizon table
    python3 exp_design.py          # finite-task upper (certified estimator) and lower (chi^2 Le Cam) bounds; fig_design.png
    python3 run_walksat.py         # 3 configs x 240 random 3-SAT instances x 10,000 WalkSAT runs (+ MiniSat labels)
    python3 exp_walksat.py         # counterfactual fixed-n evaluations; walksat_summary.csv; fig_walksat.png
    python3 exp_synthetic.py       # misspecification/coverage study; synthetic_summary.csv

`results/instances/` (CNF files) is regenerated by `run_walksat.py` (seeded) and was deleted to save space;
the run matrices themselves are stored in `results/walksat_*.npz`.

## Files
- `code/ttc.py` — library: Bernstein basis, best-approximation LP, sharp identified-set LPs, certified linear
  estimator (`LinearCertificate`), simultaneous Clopper-Pearson box interval (`box_interval`), beta-binomial and
  power-law baselines.  (`split_bounds*` are exploratory sample-splitting variants that were inferior and are not used in the paper.)
- `code/walksat.c` — minimal WalkSAT/SKC generator.
